When designers change a token in Figma, someone still has to copy that change into code by hand. It's slow, and design and code drift apart.

In this under-3-minute walkthrough, we show you how Supernova code automation fixes that. You change a token in Figma, Supernova pulls the change in, an exporter turns it into code, and Supernova opens a pull request in your repository, ready to merge.

You'll see how to:
✦ Open Code automation in your design system and create a new pipeline
✦ Pick an exporter: use a predefined one like CSS, or build your own
✦ Name the pipeline, add a theme, and preview the generated code
✦ Decide when it runs, for example every time a new version is released
✦ Choose where the code goes: GitHub repository, branch and folder
✦ Create the pipeline and let every release open a pull request with the new tokens
