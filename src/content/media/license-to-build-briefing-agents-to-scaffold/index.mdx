Getting an agent to place a Figma component on the canvas is easy. Getting it to build yours — on-system, with the right variants, states, and tokens — is where your documentation does the heavy lifting.

License to Build is a webinar series from zeroheight covering real use cases for briefing AI agents with your design system context. Practical and tools-first.

Dispatch #2: Briefing agents to build Figma components from your design system

In this session, we cover:

- How to brief an agent to build a new Figma component using your zeroheight documentation as the source of truth
- Claude Code and Figma Agents: different tools, same documentation driving the build
- Keep agents from going rogue: What good looks like, the common pitfalls, and what still needs a designer's eye

Tools covered: zeroheight MCP, Claude Code, and Figma Agents
