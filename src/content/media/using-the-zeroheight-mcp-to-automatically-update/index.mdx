Docs are usually the last bit of a component to get done, and they’re the bit that actually helps people (and agents) use it. In this video I document a brand new component, Metric Card, in our Baseline design system with one prompt, using the zeroheight MCP, Claude Code, the Figma MCP and our codebase.

The agent pulls the template and tone of voice from zeroheight, reads the component in code and the design in Figma, then builds the page with native zeroheight blocks. Then it audits the page against the Design System Documentation Spec. It scores 69% on the first pass and 97% once it’s fixed the gaps. It also flags anything it can’t resolve, and everything stays a hidden draft until a human signs off. You can also set the whole flow to run on a schedule, so your docs keep up with Figma and the repo without anyone having to remember.
