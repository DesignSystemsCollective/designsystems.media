When a component changes in Figma or in your code, two agents can draft the docs update in zeroheight for you. This walkthrough covers setting them up and running them, first by hand and then on a schedule. It uses Claude Code with the zeroheight MCP and the Figma MCP.

Get the setup guide and both skill files: https://hubs.li/Q04DTx5w0

-- The watcher checks Figma and your code for changes and logs them in a hidden ledger page in zeroheight. It never touches your docs.
-- The writer picks up the changes where design and code agree and drafts the documentation update for a person to review and publish.

When only one side changes, it’s flagged as drift for your team to sort out rather than be documented.

This is the follow-up to License to Build Dispatch #4. Watch the full session for the best practices and the gotchas we hit along the way:  https://hubs.li/Q04DTC2S0
