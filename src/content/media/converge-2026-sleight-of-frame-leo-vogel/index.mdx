Converge is zeroheight’s annual design systems conference. In 2026, we hosted the event at the Glasshouse, Newcastle, on 22nd October.

SPEAKER: Leo Vogel

TALK: Sleight of Frame: Practical Figma Tricks for Components That Warn, Vanish, and Explain Themselves.
Every Figma component you build makes a promise about how it should be used - and then people use it some other way. This talk covers the techniques that close that gap: keeping implementation-only pieces out of the assets panel, adding an annotation layer anyone can switch on when they need it and hide when they don’t, making a component warn someone the moment they misuse it, and retiring old components without breaking anything that already depends on them. All of it uses features already in Figma, and none of it asks a consuming designer to install a plugin. You’ll come away with a deprecation workflow you can adopt immediately.
