Every AI tool adds MCP servers in a different place: a settings page in one, a terminal command in another. So people get stuck before their agent ever reads the design system.

In this under-3-minute walkthrough, we show you how to connect the Supernova MCP to Cursor, Claude Code, Codex, Claude and ChatGPT. It works the same way everywhere: you add one URL, sign in with Supernova, and choose a design system to read and write with the Editor MCP, or an MCP server made for your team.

You'll see how to:
✦ Copy the Supernova MCP URL, mcp.supernova.io/mcp, from the MCP tab on your Overview
✦ Install it in Cursor in one click, or add it in Cursor Settings › Tools & MCPs
✦ Sign in and choose the Editor MCP or a Consumer MCP server for your team
✦ Add it to Claude Code with claude mcp add, then authenticate with /mcp
✦ Add it to Codex with codex mcp add
✦ Add it as a custom connector in Claude and as a custom MCP server in ChatGPT
