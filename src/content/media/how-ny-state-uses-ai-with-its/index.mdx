New York State fed a 5-page foster and adoptive parent application PDF into Claude Code. About 13 minutes later it had a multi-step web form built with the New York State Design System. It worked because Claude Code queried the design system MCP server for tested components, tokens and validation patterns instead of guessing.

This is the recording of Jesse Gardner's session at the Into Design Systems AI Conference 2026. Jesse (Director of Accessibility and Design Systems at the New York State Office of Information Technology Services) walks through two demos built with Claude Code. The first turns a PDF into a web form. The second generates 40 interaction patterns plus a gap analysis that his team reviewed in FigJam. Then he shows how Figma Code Connect, a custom MCP server and JSDoc usage guidance give AI the context to build accessible interfaces.

You will learn:
→ Why AI without context builds the average of the internet
→ How Figma Code Connect and the Figma MCP server return real design system code
→ How JSDoc usage guidance in your components becomes guidance for AI
→ Why an MCP server beats pointing AI at 50,000 to 80,000 tokens of raw component code
→ Which work still needs designers after AI builds the form
