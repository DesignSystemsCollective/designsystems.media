Your design system lives in Figma, in code, in documentation, and now in every AI agent your teams use. Keeping all of it in sync by hand doesn't scale.

In this 5-minute walkthrough, we show you the fundamentals of Supernova, the agentic design system platform. It brings your design and code data into one place, documents it, and delivers it to your teams and their agents. Then feedback from people and agents flows back, so your system keeps getting better.

You'll see how to:
✦ Connect Figma, Figma variables, Tokens Studio, Storybook and your codebase
✦ Manage design tokens with values for every theme and the CSS names your code already uses
✦ Keep icons, illustrations and components in one linked record across design and code
✦ Write documentation with live blocks, and publish it publicly or behind sign-in
✦ Turn design changes into code with exporters and pull requests
✦ Track docs analytics, code adoption and MCP usage
✦ Ask the Supernova agent to write and update your docs, or connect Cursor, Claude Code and Codex
✦ Deliver scoped contexts to each team over MCP, and collect feedback from their agents
