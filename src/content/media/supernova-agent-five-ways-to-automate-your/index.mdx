A design system is never finished. Keeping it up to date while it supports the whole organization means an endless list of docs, tokens, components, and requests from every team.

In this under-3-minute walkthrough, we show you how the Supernova Agent automates your daily design system operations, with five examples to spark ideas. The agent works with everything in Supernova, knows the page you're on, and asks before it publishes or deletes anything.

You'll see how to:
✦ Ask the agent for a health check and see what's missing in your design system
✦ Document the components that have no docs, with dos and don'ts, linked and kept in draft
✦ Find tokens nothing uses and fill in missing descriptions, with deletes waiting for your approval
✦ Tell the agent what your teams build and get a dedicated MCP server for each team
✦ Turn the feedback agents leave on your MCP servers into doc, token, and component fixes
