When code changes in a pull request, an agent can review it against what your team has documented in zeroheight. This walkthrough covers setting the audit up on GitHub and then a real run on a pull request. It uses a GitHub Action with the zeroheight MCP and your model provider's API.

Get the setup guide and templates: https://hubs.li/Q04G75Hm0

– The audit checks each change against your component guidelines and matches hardcoded values against your tokens. Every finding links back to the zeroheight page it comes from.
– The results land on the pull request as a summary and comments on the exact lines, with suggested fixes the reviewer can commit in one click. Every push runs it again.

You'll need a zeroheight Enterprise plan to create the read-only API token.

For a deep dive on this use case, including how to roll it out with your team and the questions design system teams asked live, watch the full session of License to Build, our webinar series: https://hubs.li/Q04G75-V0
