When a designer changes a component in Figma, the documentation never hears about it. Someone has to update the page by hand, and the docs go stale one decision at a time.

In this under-2.5-minute walkthrough, we show you how Supernova keeps your documentation up to date. Pages are built from your design data, agents write the words, from Figma or right in Supernova, and your team reviews and approves every change before it goes live.

You'll see how to:
✦ Ask the Supernova connector from the Figma agent to document a new variant over MCP
✦ See documentation built from your design data, with the variants coming straight from Figma
✦ Ask the Supernova Agent to edit several pages in one go
✦ Review what the agent changed in page history, and roll back to an earlier snapshot
✦ Request a review and mark pages ready for publish with the approval workflow
✦ Edit the same page together with your team, live
✦ See which pages people actually read with Docs analytics
